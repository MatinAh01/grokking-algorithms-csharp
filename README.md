# grokking-algorithms-csharp

C# exercises and personal notes for Grokking Algorithms by Aditya Y. Bhargava (first edition, 2016).

## Structure

- `Program.cs`: run the exercise currently being studied and print results.
- `Chapter02/SelectionSort.cs`: Chapter 2 exercise implementations.
- `notes/big-o.md`: complexity notes written in my own words.

Add chapter folders as new topics are reached.

## Run

From the repository folder:

```sh
dotnet run
```

## Current exercise

Implement a method that returns the index of the smallest element in a nonempty `int[]`, then call it from `Program.cs` with a small example.
